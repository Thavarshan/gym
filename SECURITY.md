# Security Policy

## Supported versions

Security fixes are applied to the latest supported `main` and the most recent v3 release.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting feature for this repository. If that feature is unavailable, contact the maintainer at the email address listed in the repository's MIT license with a concise report containing:

- A description of the impact and affected component.
- Reproduction steps or a minimal proof of concept.
- The version, platform, and configuration involved.
- Any suggested mitigation, if known.

You can expect an acknowledgement within seven days. We will investigate, coordinate a fix, credit reporters when requested, and publish a security advisory after remediation.

## Scope

In scope: the Gym CLI source, release archives, CI workflows, bundled dependencies, and documented data handling.

Out of scope: vulnerabilities in unsupported forks, compromised local machines, social engineering, and reports that require access to data not owned or authorized by the reporter.
