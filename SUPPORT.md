# Support

## Get help

- **Usage questions and setup help:** open a GitHub Discussion.
- **Feature ideas:** start a GitHub Discussion before filing a feature request when the proposal is broad.
- **Reproducible defects:** use the bug-report issue form.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not post publicly.

When asking for help, include the Gym CLI version, operating system, installation method, relevant command output, and a minimal set of steps that reproduces the issue. Do not include passwords, invoices, customer data, or database files.
